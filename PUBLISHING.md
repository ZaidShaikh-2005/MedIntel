# Upload the MedIntel README package

Repository: https://github.com/ZaidShaikh-2005/MedIntel

## Through GitHub's website

1. Extract `MedIntel_README_Package.zip`.
2. Open the **MedIntel repository homepage**. Do not upload inside `app/templates/app`.
3. Select **Add file → Upload files**.
4. Open File Explorer alongside your browser.
5. Drag **README.md**, the **docs** folder, and **PUBLISHING.md** into GitHub’s upload area.
6. Enter “Add professional MedIntel README and media” as the commit message.
7. Commit to **main**, or use your repository’s normal branch workflow.
8. Return to the repository homepage to see the banner and GIF.

The file picker may show only files; drag the **docs folder** from File Explorer into the upload area to retain its subfolders.
